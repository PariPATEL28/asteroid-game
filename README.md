## Installation

This game requires Python and the `if3_game` library used during my Interface3 training.

The library is not included in this repository. You will need access to the course-provided file:
`if3_game-2022.3.1-py3-none-any.whl`.

1. Download this repository using **Code → Download ZIP**.
2. Extract the ZIP.
3. Place the library's `.whl` file in the extracted game folder.
4. Open a terminal in that folder and install the library:
   ```bash
   python -m pip install ./if3_game-2022.3.1-py3-none-any.whl
   ```
5. Start the game:
   ```bash
   python main1.py
   ```
6. left, right, up, down arrow for space direction and space key for shoot and space move.
